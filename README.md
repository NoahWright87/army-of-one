# Army of One

A game where you control an army, one soldier at a time.

You play one soldier per life. When you die, your past lives replay as **echoes** beside your
next soldier. Save a soldier you previously watched die, and you can later resume them from an
**O** on the timeline. Read the full vision in
[`army-of-one-product-design.html`](army-of-one-product-design.html), the product owner's rulings
in [`docs/DECISIONS.md`](docs/DECISIONS.md), and the build plan in [`todos/`](todos/README.md).

## Quick start

```sh
npm install
npm run dev       # play in the browser (Vite dev server)
npm run test      # headless unit + scenario tests
npm run sim       # run the simulation headless from the CLI
```
