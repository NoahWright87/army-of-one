# Miniature art

Final art for the collectible-miniature look goes here (`base_*.png`, `figure_*.png`, `hull_*`,
`turret_*`, `wreck_*`, `shadow_*`), named exactly as in `src/content/miniatures.ts`.

The brief is in [`docs/art/`](../../docs/art/README.md). Start there. Check what you've delivered with
`npm run check:art` (add `-- --sheets` to render review sheets into `_review/`, which is git-ignored).
